# 16. 列印文件標準（大標題／頁碼／文件編號）

> 2026-07-31 制定，起因：外來文件清單列印版定案時使用者明確要求全站列印文件比照辦理。
> 分頁機制本身依然遵守 print_pagination 鐵則（單一表格交給瀏覽器引擎原生分頁、禁止 JS 量高度自算分頁），本篇只規範「頁面上要印哪些固定元素、印在哪」。
> 標準示範頁：`views/Sales/external_doc_list.php` 的列印段（`#btnPrint` handler），新頁面照抄改字即可。

## 一、大標題＝本公司全名（發票用），動態取、禁寫死

- 每份列印文件最上方**大標題＝本公司公司全名**，第二行＝文件名稱（如「外來文件清單」）。
- 公司全名的唯一來源：`customer_list.is_own_company = 1` 那筆的 `customer_full`（客戶全名·發票用；空則退 `customer`）。這筆資料在主檔管理（master_data_management）客戶頁維護，改公司名只改主檔、全站列印跟著變。
- **禁止把公司名寫死在頁面裡**（2026-07-30 供應商稽核已因此改過一次）。程式裡只允許 try/catch 的最後 fallback 字串。
- 可直接抄的取法（`src/store/ExternalDoc_API.php` 的 `extdoc_company_name()`、`src/common/vendor_audit_lib.php` 的 `vendor_audit_company_name()`）：
```php
$st = $db->query("SELECT customer_full, customer FROM customer_list WHERE is_own_company=1 LIMIT 1");
```

## 一之二、表頭（大標題下方那一行）＝已綁定 AS 文件的「表單名稱」，動態取、禁寫死

> 2026-08-03 補列（使用者明確要求，全站列印文件適用）。這裡的「表頭」**不是** table 的 `<thead>`，指的是大標題（公司全名）**正下方那一行標題文字**。

- 有綁定 AS 文件編號的列印文件，**表頭一律＝該 AS 文件的 `doc_name`（表單名稱）**，不可在頁面裡寫死標題字串。
  - 例：結構總覽綁定 `2-DC-01-01 文件管制總覽表` → 表頭自動印「文件管制總覽表」；日後表單改名只改 AS 文件主檔，列印跟著變。
- 三件事一次到位：**大標題＝公司全名（第一節）｜表頭＝綁定 AS 文件的表單名稱（本節）｜頁尾右下＝該 AS 文件的 `doc_no`（第三節）**——後兩者同一筆綁定資料，取 `doc_name` 與 `doc_no` 即可，不要各取各的來源。
- 未綁定時才退回頁面自訂的預設標題（如「AS 文件結構總覽」），並且右下角不印編號。
- 綁定值一律存設定（`system_settings` 或 `system_parameters`）只存 `as_document.id`，**禁止把編號/名稱字串存進設定**（改名或換版就對不上）。
- 可直接抄：`src/store/AS_Document_API.php` 的 `asTreeBoundDoc()`＋`views/ADM/as_document_management.php` 的 `#btnTreePrint`（結構總覽列印）。

## 二、頁碼＝左下角「第 X 頁／共 Y 頁」，多頁才顯示

- 統一印在**頁尾左下角**，格式「第 X 頁／共 Y 頁」。
- 一律用 `@page { @bottom-left { content:'第 ' counter(page) ' 頁／共 ' counter(pages) ' 頁'; } }`，由**列印引擎在列印當下計算**——換印表機頁數變了頁碼也自動正確。禁止 JS 自己算頁數寫進頁面。
- 「多頁才顯示」的判斷：以 A4 概算 `document.body.scrollHeight > (297-頁邊mm)*96/25.4*0.92` 才動態插入上面那條 style。這個量測**只決定頁碼顯示與否，完全不影響分頁**，不違反 print_pagination 鐵則（quotation_list_test.php 既有作法）。

## 三、文件編號（AS 表單編號）＝頁尾右下角

- 有綁定 AS 文件編號的報表/表單，`doc_no` 一律印在**頁尾右下角**：`@page { @bottom-right { content:'2-XX-XX-XX'; } }`（每頁都有，不是只有最後一頁）。
- 編號來源一律走 `as_document` 綁定（各模組自己的綁定設定，如 system_parameters `EXTERNAL_DOC/as_doc_id`），禁止寫死編號字串。
- 動態塞進 content 字串前先把 `'` 與 `\` 濾掉（`String(docNo).replace(/['\\]/g,'')`），避免撐破 CSS。

## 三之二、簽章（含代理人代簽「代」字）

> 2026-08-03 制定（使用者明確要求，全站列印文件一體適用）。起因：線上檢驗記錄表列印版只印人名，紙本簽核看不出是誰、哪一天核的。

- **簽章欄不可只印人名**，一律用共用元件 `resource/js/eg_stamp.js` 的 `EGStamp.stamp(name, date, isDeputy)` 產生**帶日期的印章**（有上傳掃描章的人自動改用實體章去背圖＋動態日期帶，沒上傳的人用 SVG 回墨印）。頁面要先載入 `eg_stamp.js`，並把本公司全名放進 `window.__ownCompany`（同第一節的取法）。
- **簽章日期的認定**：已存檔的單據一律用**該單據的業務日期**（檢驗記錄表＝檢驗日 `check_date`），不是列印當下的日期；尚未存檔的現場列印才用今天。同一份文件的所有簽章共用同一套認定方式。
- **印章自帶日期，所以簽章欄旁邊不要再開一個「日期」欄**；文件本身的日期印在資料表格**最右上角**的格子。
- **代理人代簽必須看得出來**：簽章右下角加「**代**」字（`EGStamp.stamp(name, date, true)`，元件已內建）。代理人一律由 `src/common/delegate_lib.php` 的 `eg_resolve_signer()` 解析（ai-rules/11），**禁止各頁自己猜代理人**；解析出來的人 ≠ 原簽核人時 `is_delegated=true`，就是要蓋「代」字的情況。
- **可選簽章人的名單怎麼來**（2026-08-03 定案）：不要為了某一張表單去 `org_role_setting.php` 加一個「某某表單簽章人」角色——一個部門常有課長／副課長／組長多位主管，表單層級的「這張單該誰簽」屬於該模組的設定，塞進全站組織綁定會愈長愈雜。正確做法是**部門取自組織角色綁定、人由模組自己挑**：`eg_org_dept_ids($db,'qc_dept')` 取部門（含子部門）→ `eg_org_dept_managers($db,$ids)` 取該部門**所有主管**（＝職稱在 `position_level` 有 level 者，已依職級由大到小排序）→ 交給 `eg_people_list()` 產生下拉（只列在職、標記長期請假、顯示職稱）。只需要自動推算「唯一一位部門主管」時才用 `eg_org_dept_manager()`。
- **自動核可**（系統代替主管蓋章）要有**設定開關＋指定核可人**，並用獨立功能碼授權哪些角色可改（例：線上檢驗 `qc_print_approve_setting`），設定值存 `system_settings`。沒啟用時該欄留白給人手簽。

## 四之二、取消瀏覽器自己的頁首／頁尾（2026-08-03 使用者明確要求，全站列印一體適用）

列印出來最上面那條「網頁標題　about:blank」、最下面那條「日期　網址」**是瀏覽器加的，不是我們的內容**，正式表單上出現這些字很難看，一律要拿掉。

- 做法：**`@page { margin: 0 }`**，版面留白改用 `body{padding:10mm 8mm 12mm}`。頁邊界為 0 時瀏覽器沒有位置畫自己的頁首/頁尾，就不會印出來（不必叫使用者自己去列印設定取消勾選「頁首及頁尾」）。
- 代價：`margin:0` 之下 `@page` 的 margin box（`@bottom-left`/`@bottom-right`）也沒有空間，**第二、三節的頁碼與文件編號要改用 `position:fixed` 的元素**印在每一頁：
  ```css
  .pt-foot{position:fixed; right:8mm; bottom:5mm; font-size:9pt; color:#333;}  /* 文件編號 */
  ```
- 頁碼：`position:fixed` 拿不到 `counter(page)`。**單頁報表不印頁碼**；確定會多頁的文件才保留原本的 @page margin box 寫法（此時瀏覽器頁首頁尾就得靠列印設定關閉，二選一）。判斷原則：紙本表單（計畫表、明細表、簽到表）優先「乾淨版面」；長清單型報表優先「頁碼」。
- 欄位多的橫式報表（例如 12 個月份欄）用 `@page{size:A4 landscape}`，不要硬塞直式。

## 四之三、排版：標題階層與欄寬（避免中文被擠成一長條）

- **大標題（公司全名）22px 粗體、副標題（表單名稱）16px 粗體**，兩者字級要拉開才有層次；副標題下方可放一行 11px 的補充資訊。
- 表格一律 `table-layout:fixed` ＋ `<colgroup>` 明確配置每欄百分比寬度，文字欄加 `word-wrap:break-word`。
  **不要只寫 `width` 在 `<th>` 上**：欄一多，瀏覽器會把中文欄壓到剩一個字寬、整欄變成直排一長條（教育訓練計畫表踩過）。
- 文字欄（課程名稱、對象、單位）左對齊；數字/代號欄置中。

## 五、既有頁面

既有列印頁（如 quotation_list_test 頁碼在 @bottom-center）不強迫回頭改（鐵律4），但**新做或大改列印版時**一律改到本標準：大標題公司名動態取、頁碼左下、文件編號右下。
