## 三、這個環境怎麼驗（下一個 session 直接照抄）

1. **偽造 session**（`userName` 要用**帳號**不是中文姓名，超管帳號＝`e`；中文會撞 `user` 表 latin1 欄位 3854 錯誤）：
   ```php
   $sid='iatest'.time();
   $out=''; foreach(['id'=>1,'userid'=>1,'userName'=>'e'] as $k=>$v) $out.=$k.'|'.serialize($v);
   file_put_contents('C:/MAMP/bin/php/sessions/sess_'.$sid, $out);
   ```
   **session 會被 PHP GC 清掉**，跑久了要重建（症狀：API 回「未登入」）。

2. **渲染後的 inline JS 一定要跑 `node --check`**（`php -l` 抓不到）。

3. **`php -l` 也抓不到「重複的 case 區塊」**（PHP 允許重複 case 標籤，後面那份只是永遠跑不到）。
   用腳本切檔案時若用 `s.index(endmark)` 抓結尾，很容易抓到**更前面**的同名字串而把整段複製一份——
   2026-09-17 就這樣把 `InternalAudit_API.php` 複製了 713 行而 `php -l` 照樣通過。
   **改完一定要驗**：`grep -n "^case " 檔案 | awk -F"'" '{print $2}' | sort | uniq -d` 必須是空的，並看 `git diff --numstat` 的增減量合不合理。

4. **無頭 Chrome**：`--headless=new --remote-debugging-port=PORT --user-data-dir=<每次新目錄>`，
   自寫極簡 CDP over WebSocket（node 內建 net/crypto/http 即可，不必 puppeteer；可直接抄本次的寫法）。
   - **收尾只終止自己啟動的 PID**（鐵律9），禁用 `taskkill /IM chrome.exe`。
   - 測試開頭先把 `alert`／`confirm` 換掉，否則 renderer 卡死、之後所有 `Runtime.evaluate` 都不回來。
   - node 輸出導到 pipe 是全緩衝，被 timeout 殺掉就什麼都看不到 → 用 `fs.appendFileSync` 寫 trace 檔。

5. **Git Bash 的 heredoc 會吃掉一層反斜線**：用 `python - <<'PY'` 塞含 `\'`／`\n` 的 JS 字串時會被改掉，
   這種內容一律改用 Write 工具寫成檔案再讀進來，或直接用 Edit 工具。

6. **健檢**：`check_sidebar.php`、`check_input_rules.php`、`check_asof_position.php` 三支都要過。

7. **測試資料一律還原**：先 `SELECT` 備份成 JSON → 測完逐列還原並比對（本次用 `att_backup.php` 的 dump/restore/verify）。
