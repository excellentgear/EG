## 4. 已知的坑（這個模組已經踩過，不要再踩一次）

1. **`<option>` 上不可掛 jQuery `.data()`**：`eg_input_rules.js` 規則7 的打字篩選會用 `innerHTML` 整批重畫選項，
   掛在 option 上的資料會整個消失。症狀是「篩選過一次之後預覽就空白」，**只有實際打字篩選才看得到**。
   本模組已改用模組變數 `IDMAP`，新加的下拉也要比照。
2. **`system_parameters.param_value` 是 JSON NOT NULL 欄位**：裸字串 `auto` 會被 MySQL 以 3140 擋下、
   而 `3` 剛好是合法 JSON 存得進去 → 「有些設定存得起來、有些按了說成功卻是空的」。寫入一律 `json_encode`，
   讀取一律過 `cm_setting_decode()`（已實作）。
3. **測試腳本不要用 curl 把中文走 argv 送出**：Git Bash 會轉成 Big5，後端 `json_decode` 失敗，
   症狀看起來像「參數沒收到」。用 PHP 驅動測試。
4. **偽造 session 檔的 PHPSESSID 不可含底線**，PHP 會判定為非法 session id、直接當沒登入。
   session 檔在 `C:\MAMP\bin\php\sessions\`（CLI 的 php.exe 是另一個目錄，別找錯）。
5. **巨檔一律用 Edit 工具改**，不要用 `php -r`／`sed` 拼字串（記憶 [[feedback_no_phpr_file_rewrite]]：
   曾把 1.6MB 檔寫成 0 bytes，而 `php -l` 對空檔案照樣通過）。
6. **無頭 Chrome 一律自帶 `--user-data-dir`，收尾只殺自己的 PID**（鐵律9，禁用 `taskkill /IM chrome.exe`）。
7. `cm_people_asof()` 是簽核池與「我自己的填表身分」的來源，**不可以在裡面排除 state=99**，
   否則超級管理員連自己的單都建不了；要排除非真人帳號請在 `cm_dept_people()` 這種「給人挑的名單」做。
