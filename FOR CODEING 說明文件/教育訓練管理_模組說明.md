# 教育訓練管理 模組說明（交接文件）

> 用途：本文件供其他 AI／工程師接手修改「教育訓練管理」頁面時閱讀。內含完整檔案、資料表、API、UI、KPI、已完成/待做、與**必須遵守的專案慣例**。
> 對應 KPI：2-GM-04-01 第 19 項「人員教育訓練達成率」。最後更新：2026-07-29。

---

## 1. 模組概述
- 頁面：`views/ADM/training_record.php`（教育訓練計畫與執行管理）。
- 目的：管理各部門/年度的教育訓練「場次」（計畫→實際開課），並作為 KPI #19 的資料來源。
- KPI #19 口徑＝**場次**：達成率 = 當月「已完成(done)」場次 ÷「計畫(排除取消)」場次；依 `plan_month`（計畫月份）歸月。
- 場次分「內訓」（有講師）與「外訓」（不需講師，填開課單位）。

## 3. 資料表（皆在 `training_lib.php` 的 `training_ensure_schema()` 內以 CREATE IF NOT EXISTS + ALTER 建立）

### training_session（訓練場次：計畫+執行合一）
| 欄位 | 型別 | 說明 |
|---|---|---|

## 4. API（`src/store/Training_API.php`，action 參數）
| action | 方法 | 參數 | 回傳/作用 |
|---|---|---|---|
| meta | GET | — | perms、departments、years、cur_year、cur_month |
| list | GET | year | 該年所有場次（含 dept_name）＋各月/年度達成率 summary |
| people | GET | dept_id | 該部門人員 [{id, user_cname}]（講師/參加人員選擇用） |
| get_attendees | GET | session_id | 該場次參加名單 |
| save_session | POST | 見下 | 新增/修改場次；回 session_id |
| save_attendees | POST | session_id, attendees(JSON) | 整批取代名單；**同步 target/actual_headcount**；保留既有 signed 狀態 |
| copy_session | POST | session_id | 複製內容為新的**計畫中**場次，**不帶名單**（供分場次）；回新 session_id |
| delete_session | POST | session_id | 刪場次（連帶刪名單）；管理員 |

- save_session 參數：session_id(0=新增)、year、plan_month、dept_id、course_name、train_type、trainer、trainer_id、org_unit、hours、status、done_date、start_time、end_time、location、note。
  - train_type=external 時後端會清空 trainer/trainer_id；internal 時清空 org_unit。
- attendees JSON 格式：`[{user_id, user_name, dept_name, attended(0/1)}, ...]`。

## 5. 權限（RBAC，module='training'，fail-closed）
- 角色：`training_view`(訓練檢閱)、`training_edit`(訓練登錄)、`training_admin`(訓練管理員)；能力階層 admin⊃edit⊃view。
- 系統管理者（user_status 9/90 或系統 admin 角色）固定全權。
- 權限判斷在 `training_lib.php` `training_perms()`；指派於「使用者權限設定」頁（prefix train）。

## 6. UI 結構（training_record.php）
- **工具列**：年度、部門、狀態、搜尋、新增訓練場次(btnAdd)、匯出CSV、列印、角色徽章。
- **統計條**：年度達成率 + 12 月各月達成率 pill（<95% 紅字）。
- **清單表**：月份｜對象部門｜課程名稱｜類型(內/外訓)｜講師/開課單位｜時數｜應到｜實到｜狀態｜實際開課日｜操作(編輯/複製/刪除)。
- **編輯 modal**（id=edMask，class wide）：
  - 基本：年度、計畫月份、課程名稱、對象部門、訓練類型(edType)、時數。
  - 內訓區(edInternalBox)：講師 = 部門(edTrainerDept)→人員(edTrainerPerson) 下拉帶入文字(edTrainer)，也可直接打字（外部講師）。
  - 外訓區(edExternalBox)：開課單位(edOrgUnit)。切換由 `applyType()` 控制顯示。
  - 實際開課：狀態、實際開課日、時段起訖、上課地點、備註。
  - **應參加人員名單**：部門(attDept)→載入人員 checkbox(attPeopleBox)→「加入勾選人員」進名單；名單表(attBody)含姓名/部門/實到 checkbox/簽名狀態/移除。名單存於 JS 變數 `ATT`，儲存時先 save_session 取得 session_id 再 save_attendees。
  - 「列印簽到表」按鈕 = `printSignSheet()` 開新視窗印 A4 簽到表（課程/講師或單位/日期時段地點/簽名欄）。
- 複製場次：清單「複製」= `copySession()` 呼叫 copy_session。

## 7. KPI 計算（training_lib.php `training_kpi_compute`）
- den = 該年月 plan_month 的計畫場次（status<>'cancelled'；參數 include_cancelled=1 則含取消）。
- num = 其中 status='done' 場次。
- value = den>0 ? num/den*100 : null。
- 已於 `kpi_as_lib.php` registry key `training_completion` 註冊；指標 #19 source_mode=auto。

## 9. 修改時必守的專案慣例（重要）
- **語言**：一律繁體中文回覆與註解。
- **配色**：一律**暖色系**（橘/琥珀/砂/赭/暖棕/珊瑚紅），禁止冷暖混雜或亂數上色；同語意同色。顏色不可為唯一資訊，需搭配文字。詳見 `ai-rules/10-配色與文字可讀性.md`。
- **UI 互動規範**（`ai-rules/08`）：輸入欄位有值雙擊清空、聚焦已有資料自動全選、Enter 跳下一欄/最後一欄送出（textarea 內 Enter 換行）；數字框無上下鈕、尾 0 省略；日期欄要能點月曆。清單 >10 筆分頁（每頁 5/10/20/50，分頁鈕右上）。
- **權限**：每頁新增/修改/刪除/檢閱角色分開設定；唯管理者固定全權。新頁面要到 user_permissions.php 加角色區塊、並登記進選單（system_module_pages）。
- **執行 SQL**：`& C:\MAMP\bin\php\php8.3.1\php.exe C:\MAMP\htdocs\EGsystem\ai-rules\tools\sql.php "SQL"`（中文用 --file；一次一句；固定連 port 3306）。**勿用 mysql.exe**。
- **PHP 語法檢查**：`& C:\MAMP\bin\php\php8.3.1\php.exe -l 檔案`。
- **收尾**（每改一檔完成即做）：php -l 通過 → `git add` → `git commit` → **`git pushall`**（雙 remote，勿只用 git push）→ 寫入 `page_change_log`（INSERT 一列 page_name/summary/detail/NOW()/'Claude'）。
- **巨檔**：超過 2000 行的檔案禁止整檔 Read／Write，只能 Edit（錨點含前後 2-3 行原文）。training_record.php 目前約 500 行，可整讀但仍建議精準 Edit。
- DB 寫入用 transaction；不破壞既有功能，只新增或修 bug。

## 10. 已知注意事項
- 應到/實到人數：**一旦使用參加名單，人數以名單為準**（save_attendees 會覆寫 target/actual_headcount）。若要保留手動人數欄位需另議。
- copy_session 只複製課程內容（year/plan_month/dept/course/type/trainer/org_unit/hours/note），狀態設 planned，**不複製名單、不複製實際開課日/時段/地點**。
- user 表部分帳號為公用/系統帳號（user_status=90，如「報工公用」「生管公用」），列人員時未特別排除，如需排除請在 people action 加條件。
