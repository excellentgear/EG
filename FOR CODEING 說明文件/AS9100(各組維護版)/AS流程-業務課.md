## 一、課室職責（摘自 2-GM-01 管理責任與經營規劃程序）

- 審查客戶之合約與訂購單；協調客戶並擬定報價單與必要之合約文件
- 保存訂單或合約審查記錄、後續作業記錄及客戶訂購單、與客戶之合約
- 將客戶採購訊息傳達給有關部門
- 顧客滿意度調查及有效處理顧客回饋事項
- 客供品之接收及記錄
- 國內外新市場、新產品之情報收集及開發
- **外來文件之接收、存檔、每季查新版**（2-DC-01）
- 顧客/外部供應商財產遺失損壞時向對方報告（2-MM-02、2-WH-01）

## 三、各程序流程與使用表單

### 2-SM-01 合約訂單審查管理程序

**適用範圍**：業務課承接之客戶業務訂單、合約、標單、開發樣品訂單、量產訂單、預估訂單，以及**經雙方書面或電子方式約定視同訂單之文件**（如回簽報價單、簽核圖面）。

**流程重點**：

1. **新產品開發**
   - 業務彙整客戶詢價資料/樣品 → 製作「產品規格需求表」
   - **例外**：若客戶有提供圖面則以圖面為準；無圖面但有完整加工數據，可不製作產品規格需求表
   - 轉技術課依 2-TD-02 以「產品開發評估表」審查
   - **產品安全**：核對客戶提供之產品安全資料，依產品開發評估表之產品安全項目審查；影響安全事件結果須通知客戶
   - **仿冒零件防制**：核對客戶提供工程資料版別清單、材料及零組件清單；檢驗分析報告回報客戶

2. **既有產品銷售**
   - 庫存足 → 完成訂單作業後依 2-WH-01 出貨
   - 庫存不足 → 依 2-PD-01 生產
   - **庫存不足時下次出貨需與客戶確認是否備庫**；客戶同意須提供訂購單；客戶無法提供訂單時，**以「聯絡單」送簽總經理**後執行

3. **詢價報價**
   - 既有產品：依先前開發件價格；客戶議價時開「報價單」呈主管簽核後報價
   - 新產品：依圖面或「產品開發評估表」會同相關單位估算成本 → 填「報價單」→ 主管核准後報價
   - **客戶特殊要求**：報價時一併審查是否能達成，並附註於報價單

4. **協調與確認交期**：業務依生管「生產排程表」與生管、客戶協調確認；交期無法達成由業務主管與相關單位討論對策

5. **訂單審查**
   - 核對客戶訂單之**圖面、版次、價格、數量、交期**與報價單相符
   - 於客戶訂單上簽章 → 主管簽核 → **掃描上傳 ERP** 作為審查依據
   - 客戶未詢價即下單 → 補作詢報價程序

6. **接單**
   - 業務將「客戶訂購單」填打至 ERP，客戶訂單掃描存檔
   - 訂單、圖面轉技術課製圖審查（依 3-TD-03）→ 轉生管依 2-PD-01
   - **客戶特殊要求**（提供/歸還樣品、治具、中間製程回客戶加工等）須附註於「客戶訂購單」，並告知技術課、生管組，由生管登錄於「製程單」
   - **訂單認定**：經協議，客戶簽署之文件（回簽報價單、圖面資料）具訂單效力

7. **訂單修改**
   - 圖面設變：技術課依 2-TD-01 提「工程變更申請/審查/通知單」→ 各部門審查 → 依 3-TD-03 分發圖面 →「訂單修改審查表」掃描附於客戶訂購單附檔
   - 設變有成本 → 向客戶報價申請設變費用
   - **交期/數量修改**：業務開「訂單修改審查表」→ 生管確認回簽並同步修正「生產排程表」、寫上處置方式 → 業務掃描附於客戶訂購單附檔

8. **客戶回饋**：滿意度依 2-SM-02；客訴由品保開「品質異常處理單」依 2-QA-05；退貨依 2-QA-01

**使用表單**：產品規格需求表(2-SM-01-01)、報價單(2-SM-01-02)、訂單修改審查記錄表(2-SM-01-03)、訂單領料單(2-SM-01-04)、客戶訂購單(2-SM-01-05)、品質異常處理單(2-QA-01-01)、產品開發評估表(2-TD-02-01)、生產排程(2-PD-01-06)、異常矯正處理單(2-QA-01-04)。
（2026.08.06 v1.5 已修正：**訂單修改審查表 2-SM-01-03**、**訂單領料單 2-SM-01-04** 已補列入 §9 使用表單清單。）

### 2-SM-02 客戶服務管理程序

**客戶代號編碼**：共 5 碼＝名稱代碼 2 碼（客戶名稱新注音第一個鍵盤所顯示數字或大寫字母，如旭陽 VU）＋流水碼 3 碼（001～999）。

**流程重點**：

1. **客戶需求調查**：業務接洽時建檔「客戶基本資料表」，掌握客戶需求/期望/抱怨與市場訊息；從產業資訊/訪談/目錄/展覽/網站分析後開發新客戶；有開發價值產品填「產品規格需求表」轉技術課評估。

2. **客戶滿意度調查**
   - **每年 11 月**針對年交易額**前 5～10 大客戶**以「客戶滿意度調查問卷」調查
   - 評核項目：品質、交期、服務、價格、技術
   - 評價分數：非常滿意(10)/很滿意(9)/滿意(8)/普通(6)/不滿意(4)；**低於 6 分項目雖符合評價仍應分析原因**

3. **統計與分析**：回收問卷彙總填「客戶滿意度統計資料表」；**單項目標值 8.0**；單項平均低於目標值或單一客戶總分低於 KPI 值 → 業務依 2-QA-05 填「異常矯正處理單」檢討改善

4. **檢討評價**：每年彙總「客戶滿意度監控表」，異常項目依 2-QA-05 分析改善並持續監控

5. **客訴處理**
   - 業務接受抱怨 → 依 2-QA-01 填「品質異常處理單」或客戶格式轉品保課
   - 品保會同相關單位確認內容並研擬解決方案
   - 業務與客戶交涉改善事宜 → 業務回覆客戶處置內容及對策
   - **品保課負責將「異常矯正處理單」編號留存備查**

**使用表單**：客戶基本資料表(2-SM-02-01)、客戶滿意度調查問卷(2-SM-02-02)、客戶滿意度統計資料表(2-SM-02-03)、客戶滿意度監控表(2-SM-02-04)、產品規格需求表(2-SM-01-01)、產品開發評估表(2-TD-02-01)、異常矯正處理單(2-QA-01-04)。

## 五、跨課室協作點

- **接單主線**：業務(詢報價/訂單審查/ERP填打) → 技術課(製圖審查) → 生管(排程/發包) → 生產 → 品保(檢驗) → 倉管(包裝出貨)
- **設變**：客戶提出 → 業務與客戶確認 → 技術課 ECR → 總經理核准 → 業務發行設變資料給各單位
- **交期/數量變更**：業務開訂單修改審查表 → 生管回簽並改生產排程
- **客訴**：業務受理 → 品保分析 → 責任單位矯正 → 業務回覆客戶
- **客供品/客戶財產**：業務接收管制存放（2-WH-01 §6.5），遺失損壞由業務書面通知客戶
- **外來文件**：各單位收到交業務課 → 需發行轉文管中心
