# AS流程-生產課（PM）

> 依據「AS9100(各組維護版)」資料夾內**現行版**程序書整理｜整理日期 2026-07-30
> 生產課主責文件：2-PM-01（程序書）
> 生產課同時是多份他課程序的**執行單位**（生產管理、工安、環境、夾治具驗收保養）

## 一、課室職責（摘自 2-GM-01 管理責任與經營規劃程序）

- 監督各生產車間對基礎數據的採集
- 編製設備管理制度（生產設備管理、保養與檢修）並監督執行
- 管制製造過程；制定影響品質之生產作業標準書
- 管制生產所需之物料與工時
- 維護生產設備於良好狀況，確保適當設備之使用
- 生產人員之訓練及認可
- 依圖面、規範與客戶要求執行生產
- 維持適當工作環境；監督物料及產品之適當搬運儲存
- 配合技術課參加技術管理標準、生產工藝流程、新產品開發方案審定
- 協同品保課調查不合格產品原因並矯正

## 三、2-PM-01 設備維護保養程序

**權責**：
- **操作人員**：每日依保養表所列項目確實執行機台日常維護保養，逐次檢查並紀錄
- **生產課主管**：監督指導操作員、每月維護保養工作、處理偶發輕微故障、定期查核各機台保養狀況

**設備編碼原則**：
- 生產機器設備：`EG-001～999`
- 品檢機器設備：`QC-001～999`

**流程重點**：

1. **採購與驗收**
   - 需求單位提出申請 → 依 3-OB-01 採購管理辦法 → 總經理批示後採購
   - 生產課依採購規格驗收 → 合格於送貨單簽註接收；不合格退供應商
   - 接收後建立「**機器設備一覽表**」及「**機器設備履歷表**」

2. **保養週期**（依「機台保養卡」實施，機器保管人員執行）

| 週期 | 執行時機 |
|---|---|
| 日保養 | 每個工作日當天 |
| 週保養 | 每週第一個工作日 |
| 月保養 | 每月第一週內 |
| 季保養 | 每季（1、4、7、10 月）第一週內 |
| 年保養 | 每年**農曆過年前一週內** |

   - 屬檢驗與試驗儀器者，改依 3-QA-01 量規儀器校正管理辦法處理

3. **異常處理**：設備故障先由製造單位檢修 → 無法自行修復經**總經理核准**後洽外部廠商維修 → 維修狀況由生產課主管記載於「機器設備履歷表」

4. **報廢**：①磨耗無法整修 ②損壞無法整修 → 填「報廢申請單」依採購程序 → 生產課主管呈**總經理核定**進行報廢及銷帳

5. **工廠/設施/設備規劃**：生產課應以多方論證制定需求；廠房布置應將物料流動與搬運程度減到最小以促進同步流動，並將空間使用附加價值提升到最大

**使用表單**：機器設備一覽表(2-PM-01-01)、機台日保養表(2-PM-01-02-01)、天車保養表(2-PM-01-02-05)、機器設備履歷表(2-PM-01-03)、報廢申請單(2-MM-02-01)。

## 五、跨課室協作點

- **設備生命週期**：需求單位申請 → 採購組採購(3-OB-01) → **生產課驗收/建檔/保養/維修/報廢** → 管理課銷帳
- **量測儀器**：分流至品保課 3-QA-01（生產課設備走 2-PM-01，檢驗儀器走 3-QA-01）
- **夾治具**：技術課設計出圖 → 生管發包 → **生產課實做驗收＋定期保養＋報廢處置**（2-TD-05）
- **生產執行**：生管排程發「多次加工憑單」→ **生產主管分派人員加工** → 生產報表報工 → 品保檢驗（2-PD-01）
- **製程檢驗**：現場加工人員首件/末件確認、每小時自主檢查、每日巡檢（2-QA-04 §6.2）
- **工安**：生產課每年 1 月規劃「防護審核表」跨部門審查 → 總經理核准 → 年底管審檢討（2-MM-05）
- **環境**：生產課負責生產現場/廠房區域工作環境執行維持管理與檢查監督（2-MM-03）
- **基礎設施**：生產課負責製造軟硬體維護與基礎設施異常處理（2-MM-02）

## 六、程序書與現況不一致（建議下次改版修正）

1. **2-MM-02 §6.3.1 及 §9** 仍列「機台每季年保養表(2-PM-01-02-03)」與舊名「機台日保養表」，但該表已於 2-PM-01 1.3 版刪除、日保養表已改為「機台保養卡」——**2-MM-02 未同步改版**。
2. **2-MM-02 §6.3.3** 稱「檢測儀器校驗管理程序」，正確文件名為「量規儀器校正管理辦法(3-QA-01)」。
3. **2-PM-01-02-01 機台保養卡**在資料夾內僅為捷徑(.lnk)，且 DB 未登錄此表單（DB 只有 2-PM-01-01/02/03，其中 2-PM-01-02 登錄名為「天車保養表」而非 02-05）——**表單編號在 DB 與實體檔不一致，建議統一**。
