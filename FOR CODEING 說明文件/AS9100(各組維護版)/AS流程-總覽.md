## 四、核心業務流程（跨課室串接）

### A. 接單 → 出貨主鏈

```
客戶詢價
  └→ 業務課：產品規格需求表(2-SM-01-01) ─新品→ 技術課：產品開發評估表(2-TD-02-01)
  └→ 業務課：報價單(2-SM-01-02) → 主管簽核 → 客戶
客戶下單
  └→ 業務課：訂單審查(核對圖面/版次/價格/數量/交期) → 客戶訂購單(2-SM-01-05) 填打 ERP
       └→ 技術課：製圖/批圖 → 主管審核蓋技術課章 → 文管中心蓋發行章 → 上傳 ERP
            └→ 生管組：製程單(2-PD-01-01) + 生產排程(2-PD-01-06) + 多次加工憑單(2-PH-03-01)
                 ├→ 廠內：生產課加工 → 生產報表(2-PD-01-03) 報工
                 └→ 委外：外包商加工 → 供應商加工檢驗表(2-PH-03-03，航太)
                      └→ 品保課：檢驗記錄表(2-QA-01-06) / 首件 FAI(2-QA-02)
                           ├─合格→ 倉管組：包裝(3-SM-01) → 出貨標籤(2-WH-01-03)
                           │         → 入庫單(2-WH-01-07) → 倉庫庫存表(2-WH-01-01)
                           │         → 訂單領料單(2-SM-01-04) 出庫 → 出貨單(2-WH-01-04)
                           └─不合格→ 品質異常處理單(2-QA-01-01) → 2-QA-01 不合格品流程
```

### B. 不合格品 → 矯正鏈

```
發現不合格（進料/製程/委外/成品/客退）
  └→ 製程管制卡(2-QA-01-02) 紅色標示 + 隔離
  └→ 品保課：品質異常處理單(2-QA-01-01)
       ├→ 特採：需求部門提出 → 主管審查 → 總經理核准（成品需客戶同意）
       ├→ 重工：製程管制卡記錄 → 重工單(2-PH-03-02，外包) → 重檢
       ├→ 報廢：不合格品管制記錄表(2-QA-01-03)（航太：紅吊卡+噴紅漆+上鎖）
       └→ 退貨：採購辦退換 → 供應商定期評核表(2-PH-01-05) 登錄
  └→ 需矯正時：異常矯正處理單(2-QA-01-04)
       → 臨時對策(清庫存全篩) → 原因分析(魚骨/5Why) → 矯正措施 → 預防措施
       → 主要缺失 7 天 / 次要缺失 14 天回覆
       → 品保追蹤 → 總經理核准結案
```

### C. 工程變更（設變）連動鏈

```
變更來源：客戶要求 / 內部需求 / 品質異常
  └→ 工程變更申請/審查/通知單(2-TD-01-01)
       → 技術課主管審查 → 總經理核准（一律）
       → 客戶所提：業務課與客戶確認（回應期限 2 週內）
       → 需重新報價：報價單(2-SM-01-02)
  └→ 執行（一週內完成文件修改）
       ├→ 技術課：修正技術資料/重繪圖面 → 文管發行（發行章）→ 舊圖蓋作廢章
       ├→ 文管中心：更新文件管制總覽表(2-DC-01-02)（依 2-DC-01/2-DC-02）
       ├→ 生管組：更換已發行圖面 → 圖面變更簽收單(2-PD-01-07) 通知已發包廠商
       ├→ 業務課：訂單修改審查記錄表(2-SM-01-03) 附於客戶訂購單
       └→ 技術課：型態識別文件管制表(2-DC-03-01) 登錄（航太）
  └→ 驗收：品保課首件驗收（2-QA-04）
```

### D. 供應商全生命週期

```
新供應商 → 供應商資料表(2-PH-01-01)
  └→ 資材課長判定 → 總經理核准
       ├─不需評鑑→ 合格供應商清冊(2-PH-01-04)
       └─需評鑑→ 供應商評鑑稽核查檢表(2-PH-01-02) 10 項評分
                  → 供應商品質系統評鑑記錄表(2-PH-01-03)
                  → >75分 或 <75分但有改善對策 → 登錄清冊
                  → <75分 → 重新評鑑或淘汰
交易中
  └→ 進料異常/遲交 → 供應商定期評核表(2-PH-01-05)（上下半年各一次）
       品質60% = (1-不良數/進貨總數)×100；交貨40% = (1-遲交數/進貨總數)×100
       A≧95 / B 95~85 / C≦85（C 為待觀察）
  └→ C 級或低於 75 分 → 供應商稽核計劃(2-PH-01-06)（每年 3 月排定）
       → 稽核 → 不良開異常矯正處理單 → 無改善則移出清冊
  └→ 2 年無交易 → 移出清冊
航太外包
  └→ 保密暨委託加工協議書(2-PH-02-01) + 工作移轉需客戶批准（2-PH-02）
```

### E. 內部稽核鏈

```
每年 12 月：內部稽核計劃表(2-GM-06-01)
  └→ 稽核員遴選（依員工職能鑑定表 2-MM-01-10，不得稽核本身職務）→ 總經理核准
  └→ 稽核通知單(2-GM-06-02)（稽核日 1 週前）
  └→ 實施
       ├→ 系統稽核：AS稽核查檢表(2-GM-06-04)
       ├→ KPI 稽核：績效執行稽核查檢表(2-GM-06-03)
       ├→ 型態稽核：型態識別文件管制表(2-DC-03-01) → 產品型態稽核表(2-DC-03-02)
       └→ 非汽車航太件：系統稽核記錄表(2-GM-06-06)
  └→ 缺失（主要/次要/觀察）→ 內稽不符合通知單(2-GM-06-07，編號 IA+8碼)
       → 受稽單位 1 週內提改善方案、3 週內改善完成
  └→ 稽核報告表(2-GM-06-08) → 管理代表審查 → 總經理核准 → 管理審查會議提報
```
