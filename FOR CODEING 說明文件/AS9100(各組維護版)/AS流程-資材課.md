# AS流程-資材課（生管組 PD/PH、採購組 OB、倉管組 WH/SM）

> 依據「AS9100(各組維護版)」資料夾內**現行版**程序書整理｜整理日期 2026-07-30
> 資材課下轄**三組**，各自維護不同編號段的文件：
> - **生管組**：2-PD-01（生產管理）、2-PH-01～03（供應商/工作轉移/委外加工）
> - **採購組**：3-OB-01（採購管理辦法）
> - **倉管組**：2-WH-01（倉儲出入貨）、3-SM-01（包裝指導書）

## 一、課室職責（摘自 2-GM-01 管理責任與經營規劃程序）

**資材課（統籌）**：協調原物料採購及交期跟催／託外加工廠商交期追蹤／原物料倉庫出入庫管理／生產管理作業執行及原物料存量掌控／管理資材課全面工作。

**生管組**：物料需求安排、生產計畫管制、產品標準流程與工時資料收集統計、製造途程與日程安排、製造工作分派與跟催、**建立供應商基本資料、主導新供應商選擇與評鑑、合格供應商建檔、主導年度供應商評鑑輔導計劃**。

**採購組**：基礎設施（廠房/儀器設備/生產設備）之詢比議價作業、採購單價核定及變更、採購過程之供應商進度管制。

**倉管組**：工件之貨架儲位規劃監督、定位標示、進銷存管制（入庫/退庫/調撥）、搬運與儲存防護、**客戶財產之倉儲管理**、呆滯料管理、盤點計劃與實施檢討。

# 【生管組】

## 2-PD-01 生產管理程序（廠內生產主軸）

**製造令編碼**：`B-民國年月日 7碼 + 流水號 3碼`，例 B-1100910001。

**流程重點**：

1. **訂單確認**
   - 新產品：業務接單依 2-SM-01 → 轉技術課依 2-TD-02 審查可行性 → 回饋業務回覆客戶交期
   - 既有產品：業務會同生管討論交期並評估產能
   - 依 2-TD-02 決議外包項目或產銷會議評估應外包項目 → 依 2-PH-03 委外發包

2. **製令單與產品圖面**
   - 生管依客戶訂單與技術課批圖之製程順序製作「**製程單**」
   - 依製程單開立「**多次加工憑單**」並排定「**生產排程**」
   - 生產課完成加工後經「**生產報表**」報工

3. **備料**
   - **客供料**：生管交品保進料檢驗；合格移待移轉區，不合格放不合格區並開簽單讓客戶取回簽名確認
   - **自備料**：生管備料，不足依 3-OB-01 採購
   - **委外加工**：生管依 2-TD-02 製作「多次加工憑單」執行

4. **工作分派**：生產主管收到多次加工憑單後分派人員加工

5. **生產交期查核**：生管**每日**追蹤進度，落後則與生產主管或廠商協調加工順序；必要時於產銷會議協調

6. **生產資訊變更**
   - 客戶交期變更：業務依 2-SM-01 發「訂單修改審查表」→ 生管修正「生產排程」及「多次加工憑單」並於修正處簽名
   - 圖面設變：技術課依 2-TD-01 開「工程變更申請/審查/通知單」→ 生管更換已發行圖面 → 已發包產品以「**圖面簽收單**」通知廠商或相關單位主管修改

7. **成品檢驗**：品保依 2-QA-04 檢驗
8. **出貨安排**：合格後依 2-WH-01 包裝入庫出貨

**使用表單**：製程單(2-PD-01-01)、多次加工憑單(2-PH-03-01)、生產排程(2-PD-01-06)、生產報表(2-PD-01-03)、重工單(2-PH-03-02)、聯絡單(2-DC-02-01)、訂單修改審查表(2-SM-01-03)、工程變更申請/審查/通知單(2-TD-01-01)、會議記錄(2-GM-05-01)、製程管制卡(2-QA-01-02)、品質異常處理單(2-QA-01-01)、異常矯正處理單(2-QA-01-04)、檢驗記錄表(2-QA-01-06)、倉庫庫存表(2-WH-01-01)、圖面簽收單(2-PD-01-07)。

## 2-PH-01 供應商管理程序

**供應商編碼**：共 5～6 碼＝分類編碼 2 碼（中文新注音第一個鍵盤顯示之數字或大寫字母，如光陽 EU）＋流水碼 3 碼。
**適用範圍**：原物料、刀具、機器設備、零配件、設備維修、包裝品、量測儀器、校驗、委外加工、服務等廠商；**耗材類或一般事務性類供應商不列入管理**。

> ### ⚠ 先分清楚：「評鑑」「定期評核」「稽核」是三件事（現場確認）
>
> | 機制 | 用途 | 對象 | 依據表單 | 頻率 |
> |---|---|---|---|---|
> | **新供應商評鑑** | 決定新廠商能否**進入**合格供應商清冊 | 新接觸的廠商 | 2-PH-01-02 查檢表 → 2-PH-01-03 記錄表 | 新增時一次 |
> | **定期評核** | **決定是否為合格供應商**（資格維持） | **所有可能列入合格供應商的廠商都要評核** | 2-PH-01-05 定期評核表 | 上下半年各一次 |
> | **稽核** | 合格供應商中的**定期抽驗**（查核品質系統運作） | **僅從已是合格供應商中抽選**，非全部 | 2-PH-01-06 稽核計劃 ＋ 2-PH-01-02 查檢表 | 每年（現場：固定兩次，廠商數不限） |
>
> 三者評分方式不同、門檻不同、目的不同——**定期評核是資格門，稽核是抽驗**，不可混用或互相取代。

**權責**：總經理核准新供應商建立；**資材課長判定是否需實地評核**；生管組發包及交期管控（原物料/刀具/零配件）；採購組交期管控（設備維修/包裝品/量測儀器/分包商）；品保課品質管控。

**流程重點**：

1. **新供應商評鑑**
   - 生管取得供應商資訊 → 提供「供應商資料表」給對方填寫
   - 資材課長呈報總經理 → **不需評鑑**者直接登錄「合格供應商清冊」；**需評鑑**者選擇稽核員進行實地/線上/文件評鑑並製作「供應商評鑑稽核查檢表」
   - 評鑑項目 10 項：管理責任及品質系統／合約審查及文件管制／採購及鑑別追溯／製程管制及測試設備／不合格品管制／矯正與預防措施／搬運包裝儲存／文件與記錄管制／人力支援及機台調撥／急件插單及加工能力
   - **通過門檻（依「供應商評鑑懶人包」）**：分數統計於「供應商品質系統評鑑記錄表」→ **>75 分**或 **<75 分但有提改善對策** → 登錄合格供應商清冊；**<75 分**需重新評鑑或淘汰

2. **定期評核（決定合格供應商資格 — 所有可能列入合格供應商的都要評核）**
   - 生管依交貨狀況評核，品質退貨或交期延誤登錄「供應商定期評核表」，**上下半年各統計一次**
   - 評分公式：**品質(60%)＝(1-(不良數/進貨總數))×100**；**交貨(40%)＝(1-(遲交數/進貨總數))×100**
   - 等級：**A 級 ≧95 分**／**B 級 95～85 分**／**C 級 ≦85 分**；A、B 級為合格廠商列優先承製，**C 級為待觀察廠商**
   - **這是資格門**：評核結果決定該廠商能否維持在「合格供應商清冊」內

3. **稽核（合格供應商中的定期抽驗 — 只抽一部分，不是全部）**
   - 稽核對象自**已具合格資格**的供應商中挑選；C 級（或依現場門檻低分者）優先列為下年度稽核重點
   - **生管組長每年 3 月**製作「供應商稽核計劃」呈總經理；現場作法為**每年固定稽核兩次，廠商數不限**
   - 稽核依「供應商評鑑稽核查檢表」評分並填入「供應商品質系統評鑑記錄表」；不良事項依 2-QA-05 開「異常矯正處理單」；通知後查無改善且非客戶指定或獨占者，**從合格供應商清冊移除**
   - **2 年內未有交易記錄**須從清冊移除；日後再交易由總經理判定是否重新稽核
   - 年度稽核完畢後，生管將總判定結果回饋更新「合格供應商清冊」

4. **供應商管理**：客戶要求時須使用客戶核准的特殊過程資源，更動供應商須由業務向客戶申請核准；採購人員須向供應商傳達適用要求（含客戶要求及記錄保存要求）；公司及客戶或法規機構有權進入供應鏈所有適用設施與記錄

**使用表單**：供應商資料表(2-PH-01-01)、供應商評鑑稽核查檢表(2-PH-01-02)、供應商品質系統評鑑記錄表(2-PH-01-03)、合格供應商清冊(2-PH-01-04)、供應商定期評核表(2-PH-01-05)、供應商稽核計劃(2-PH-01-06)、品質異常處理單(2-QA-01-01)、異常矯正處理單(2-QA-01-04)。

## 2-PH-02 工作轉移管理程序

**適用**：對外部供應商、外部供應商對另一外部供應商、組織廠房間、外部供應商移轉至組織之工作移轉。

**流程重點**：
1. **必要性評估**（管理/生產/資材）：現有資源人力設備廠房技術產能規劃；廠房不敷使用→擴廠或移轉；廠內能力不足→移轉外包；外包商品質交期價格不佳→依 2-PH-01 評估更換
2. **客戶批准**（業務）：移轉前須依合約規定獲客戶批准；依客戶要求提供文件說明必要性；選擇客戶指定或持有相關認證之外包商
3. **作業流程**
   - 場地變更：新場地施工完成後依「多次加工憑單」生產
   - 工作外包/換外包商：依 2-PH-01 選合格供應商 → **航太類外包須簽「保密暨委託加工協議書」** → 依 2-GM-03 風險管理必要時填「風險評估及處理表」→ 圖面/規範/訂單要求/驗收標準記錄於「多次加工憑單」傳遞外包商
4. **驗證**（品保）：外包首件檢驗合格方可放行生產且記錄須保存；依 2-QA-04 允收標準抽檢；外包商須準時交貨、無法準時須提早告知；客戶要求時須提供符合性證明並允許客戶到廠稽核

**使用表單**：保密暨委託加工協議書(2-PH-02-01)、多次加工憑單(2-PH-03-01)、品質異常處理單(2-QA-01-01)、異常矯正處理單(2-QA-01-04)、風險評估及處理表(2-GM-03-01)。

## 2-PH-03 委外加工作業程序

**流程重點**：
1. **需求申請**：生管依 2-TD-02、2-PD-01 製作「製程單」→ 核准後附圖面及客戶要求；**航太件另依 2-PH-02 工作移轉程序執行**；生管掌握交期、數量及不良品回收處理
2. **驗收**：生管依「多次加工憑單」及廠商進料單點收；**航太件廠商須隨附「供應商加工檢驗表」**或其他檢驗表 → 品保依 2-QA-04 檢驗（依多次加工憑單之藍圖規範）→ 合格依製程單續下一製程；不合格依 2-QA-01
3. 必要時取得品質客觀證據（隨貨文件/合格證明書/測試報告/統計記錄/製程管制）

**使用表單**：製程單(2-PD-01-01)、多次加工憑單(2-PH-03-01)、供應商加工檢驗表(2-PH-03-03)、**航太合格供應商清冊(2-PH-01-04A)／非航太合格供應商清冊(2-PH-01-04B)**、品質異常處理單(2-QA-01-01)、異常矯正處理單(2-QA-01-04)、檢驗記錄表(2-QA-01-06)。

# 【採購組】

## 3-OB-01 採購管理辦法

**採購單編號**：`OB + 民國年月日 + 流水號`，例 OB1090303002。

**權責分工（誰請購什麼）**：

| 單位 | 請購項目 |
|---|---|
| 採購組 | 耗材、市購品 |
| 生產課 | 加工設備、刀具 |
| 品保課 | 量具、外包加工檢具 |
| 生管組 | 原物料、外包加工 |

**請購金額分級**：

| 級別 | 金額 | 核准層級 |
|---|---|---|
| 固定資產 | **8 萬元以上** | 單位主管審查 → **總經理核准** |
| 其他購置 | 2 千元以上～8 萬元以下 | 單位主管核准 |
| 雜項物品 | **2 千元(含)以下** | 各組組長填單 → 單位特助或經理核准 |

**流程重點**：
1. **請購**：填「請購單」依上表核准；並核對產品安全項目（依產品開發評估表）及仿冒零件防制（核對客戶指定原材料證明、產品序號）
2. **詢價**：依核可請購單轉「詢價單」或「採購單」向廠商詢價；**雜項物品及經常性固定消耗品可免詢價**；非經常性物品須詢比價原則向最低價者購買（特殊情況呈總經理核准）
3. **採購資訊要求**（§6.3.2，AS9100 重點）：
   - 產品、程序、過程與檢驗儀具核准要求
   - 服務人員專業知識基本要求
   - 公司或客戶對 QMS 的特別要求
   - 規格圖面製程要求檢測說明及**正確版本**
   - 供應商應**隨時通報不合格產品所有資訊**
   - 要求供應商於**產品或製程變更及工作移轉次供應商時通知本公司**，必要時取得核可
   - 允許本公司及客戶及管轄機構**進入相關場所設施取得記錄**
   - 供應商應要求次供應商遵守圖面規範（含關鍵特性）
   - **供應商須保存採購單文件 5 年**
4. **採購**：依簽核完成之請購單開「採購單」向合格供應商訂購並電話確認；雜項物品可免開採購單；急用零配件可口頭報備主管核准後事後補請購單；外包加工件須開採購單；採購單修訂須在原單修改簽章傳給供應商
   - **1.4 版新增 §6.4.7**：廠商已依請購單/採購單規格提供報價單，將廠商報價單簽名蓋章確認後，採購單內廠商回簽可免簽
5. **驗收**：採購人員依採購單點收並開「進貨單」結案；有關規格產品通知品保依 2-QA-04 檢驗 → 合格依 2-WH-01 入庫、不合格依 2-QA-01
6. **報廢**：磨耗無法整修／疏忽損壞無法整修／遺失 → 各單位填「報廢申請單」→ **總經理核准** → 送管理課報廢及銷帳

**使用表單**：請購單(3-OB-01-04)、廠商詢價單(3-OB-01-05)、採購單(3-OB-01-01)、進貨單(3-OB-01-02)、進貨退出單(3-OB-01-03)、報廢申請單(2-MM-02-01)。

# 【倉管組】

## 2-WH-01 倉儲出入貨管理程序

**權責**：生產單位（製程中、成品及交貨廠內之搬運）／倉管單位（包裝、儲存、保存）／生管單位（交貨；顧客或外部供應商財產之管制存放）／業務課（顧客財產遺失損壞之通報）。

**流程重點**：
1. **搬運**：使用天車、台車、人力等核准方法；碰撞掉落損傷交品保確認，不合格依 2-QA-01
2. **供應商原物料入出庫**：採購人員點收開「進貨單」→ 需檢驗者由生管提供藍圖規範交品保依 2-QA-04 檢驗
3. **成品入出庫**
   - **入庫**：品保檢驗合格 → 包裝人員依 3-SM-01 完成包裝 → 倉管依「入庫單」入庫並建立「倉庫庫存表」；不合格依 2-QA-01
   - **出庫**：倉管依生管提供之「**訂單領料單**」出庫並更新「倉庫庫存表」
4. **包裝、保存與交貨**
   - 按客戶別儲存於庫房架上或棧板
   - 品保最終檢驗後查證符合顧客要求且保護措施已安排；客戶無要求則依 3-SM-01 防護
   - 包裝人員依合約或法規進行包裝防護並貼「**出貨標籤**」
   - **貯存期控制與存貨周轉：依客戶規定產品壽限管控，周轉採先進先出**
   - 危險材料應獨立儲存並上鎖管控（目前不需使用）
5. **顧客或外部供應商財產**
   - 由**業務課**管制存放；**皆為免驗**，業務須先告知顧客並留下書面確認，再轉交生管附圖面開始生產
   - 業務填打訂單時須備註接收數量、存放位置及出貨時是否需一併歸還並告知生管
   - 隨工件加工移轉者，生管須註明於「多次加工憑單」並要求廠商加工完成後隨貨繳回
   - 遺失損壞：品保開「品質異常處理單」，業務書面通知顧客協同處理並保留文件化資訊

**使用表單**：進貨單(3-OB-01-02)、廠內借出單(2-WH-01-02)、檢驗記錄表(2-QA-01-06)、品質異常處理單(2-QA-01-01)、入庫單(2-WH-01-07)、倉庫庫存表(2-WH-01-01)、訂單領料單(2-SM-01-04)、製程管制卡(2-QA-01-02)、出貨單(2-WH-01-04)、異常矯正處理單(2-QA-01-04)、出貨標籤(2-WH-01-03)。

## 3-SM-01 包裝指導書

**流程重點**（最終檢驗合格後由倉管組包裝人員執行）：
1. 依客戶合約或法規要求進行包裝、防護與標記；無特殊要求則依本指導書
2. **產品先泡入去漬油清洗乾淨，再泡入防鏽油進行防鏽**（1.1 版更改）
3. 包裝時注意產品是否有污損、生鏽、撞傷、刮痕、脫漆或其他瑕疵
4. 視大小數量裝入適當紙箱；能容納泡殼則用適當大小泡殼；數量少或判定不需泡殼時以單一塑膠袋分開包裝；產品間隙用瓦楞紙/紙屑/報紙/氣泡袋隔開防撞；**紙箱內層需增加一層防水袋**
5. 紙箱較重時以打包帶綑綁固定防止底部破裂
6. **裝箱完成後核對客戶名稱、品號及數量並貼上製程管制卡**
7. 裝至鐵籠時紙箱排列盡量無空隙，必要時用空紙捲填實，外面以工業用保鮮膜封膜

**使用表單**：出貨標籤（程序書 §7.1 標 2-WH-01-07，正確為 **2-WH-01-03**；2-WH-01-07 為入庫單）、出貨單(2-WH-01-04)、製程管制卡(2-QA-01-02)。

## 四、跨課室協作點

- **接單到出貨主鏈**：業務(訂單) → 技術(批圖) → **生管(製程單/生產排程/多次加工憑單)** → 生產(加工/報工) → 品保(檢驗) → **倉管(包裝/入庫/出貨)**
- **採購鏈**：需求單位(請購單) → **採購組(詢價單/採購單)** → 供應商 → 採購點收(進貨單) → 品保檢驗 → **倉管入庫**；不合格→進貨退出單
- **委外鏈**：生管(製程單/多次加工憑單) → 外包商 → 生管點收(航太附供應商加工檢驗表) → 品保驗收 → 續下一製程
- **供應商全生命週期**：生管建檔評鑑(2-PH-01) → 採購/生管交期管控 → 品保品質管控 → 進料異常回饋定期評核表 → C 級列年度稽核 → 不改善移除清冊
- **設變連動**：技術課 ECR → **生管以圖面變更簽收單通知已發包廠商**
- **客戶財產**：業務接收管制 → 生管存放 → 隨工件移轉註記於多次加工憑單 → 出貨時依註記歸還
