## 三、各程序流程與使用表單

### 2-TD-01 工程變更管理程序

**流程重點**：
1. **申請**：各單位（含客戶需求）填「工程變更申請/審查/通知單」→ 技術課主管審查 → **總經理核准**（所有工程變更均需總經理核准）。
2. **客戶所提變更**：業務課與客戶確認 → 技術課主管核准；需重新報價則依 2-SM-01 開「報價單」；客戶提出至回應期限：客戶要求時間內或**二週內**。
3. **執行**：客戶設變由業務發行資料給相關單位；製程變更由技術課修正技術文件、文管中心依 2-DC-01/02 更新；相關文件修改應在**一週內**完成；涉及分包商由生管通知。
4. **驗收**：品保依 2-QA-04 進行**首件驗收**。
5. 所有變更應有**生效日期**以便追溯。

**使用表單**：工程變更申請/審查/通知單(2-TD-01-01)、報價單(2-SM-01-02)、品質異常處理單(2-QA-01-01)、異常矯正處理單(2-QA-01-04)。

### 2-TD-02 製程開發作業程序（APQP）

**適用**：航太件走完整五階段；一般零件簡易流程。

**五階段流程**：
1. **第一階段：可行性評估**
   - 業務彙整客戶要求/圖面/品質規範 → 技術課組成跨功能小組 C.F.T.（業務/技術/品保/資材/生產，必要時含客戶供應商）
   - **兩個工作週內**（或依客戶要求期限）完成客戶圖面及特殊要求審查
   - 人機料法環＋風險評估記錄於「產品開發評估表」（含產品安全、仿冒零件防制項目）
2. **第二階段：開發計劃核准**
   - 「產品開發評估表」核准後生管督導跟催
   - 工程輸出：規格圖面/製程單/PFMEA/製造製程說明書(非必要)
   - 關鍵特性於圖面標註客戶符號或自訂「☆」
   - 圖面流程：製作加工圖→批圖→技術課主管審核→文管發行
3. **第三階段：樣品/量試製作**：技術課出圖 → 生管依 2-PD-01 製作 → 生產課依「多次加工憑單」試製 → 量具依 3-QA-01 校驗合格
4. **樣品測試送樣**：品保依 2-QA-04 首件檢測記錄於「檢驗記錄表」→ 生管送樣客戶評核
5. **第四階段：量產**：客戶承認下單 → 業務依 2-SM-01 接單
6. **第五階段：回饋與矯正**：品保依管制圖監控變異、業務依 2-SM-02 追客戶滿意度、依 2-QA-05 改善提案

**使用表單**：產品規格需求表(2-SM-01-01)、產品開發評估表(2-TD-02-01)、PFMEA評估準則(3-TD-01-01)、潛在失效模式及效應分析(3-TD-01-02)、製程單(2-PD-01-01)、檢驗記錄表(2-QA-01-06)、工程變更申請/審查/通知單(2-TD-01-01)。

### 2-TD-03 產品安全管理程序

**流程重點**：各課依所屬程序執行產品安全內容（管理課→基礎設施/環境/工安；業務→合約審查；技術→製程開發；採購→採購辦法；生產→生產管理）；發生影響安全事件時：填「產品安全審核表」→ 據以填「風險評估及處理表」→ 不合格品依 2-QA-01、矯正依 2-QA-05 → **業務將結果通知客戶** → 結案報告納入年度教育訓練。

**使用表單**：風險評估及處理表(2-GM-03-01)、產品安全審核表(2-TD-03-01)。

### 2-TD-04 仿冒零件的防制作業程序

**流程重點**：技術課依 2-DC-03/2-DC-04 執行產品鑑別追溯製程技術並填「仿冒零件防制審核表」；資材課從授權來源取得產品並確保追溯性、區隔疑似仿冒件；品保執行零件淘汰監控與檢驗分析報告；業務將報告回報客戶；管理課年度教育訓練。

**使用表單**：仿冒零件防制審核表(2-TD-04-01)。

### 2-TD-05 夾治具管理程序

**編碼**：通用 `JIG-YY-ZZZZZ`；航太 `AS-XX-YY-ZZZZZ-R-(01)`（設備碼：LA車床/TG齒研/HB滾齒）。

**流程重點**：
1. **新製**：開發會議決定 → 技術課繪圖審核 → 生管依 3-OB-01 開採購單備料、依 2-PD-01 發包 → 生產課實做驗收 → 移交使用單位保管維護 → 建「夾治(檢)具履歷表」。
2. **設變/維修**：使用單位說明項目 → 主管核可 → 技術課出圖、生管發包 → 生產課驗收 → 記錄履歷表；驗收不合格依 2-QA-01。
3. **保養**：生產課定期保養記錄於履歷表。
4. **報廢**：主管核可 → 技術課主管確認 → 可用則維修、不可用則生產課填「報廢申請單」並於履歷表標示報廢。

**使用表單**：夾治(檢)具履歷表(2-TD-05-01)、採購單(3-OB-01-01)、報廢申請單(2-MM-02-01)。
（另有表單檔 2-TD-05-02 夾具清單，程序書 2.0 版未列入使用表單清單。）

### 3-TD-01 失效模式及效應分析應用辦法（PFMEA）

**流程重點**：PFMEA 由技術課主導，為動態文件，於產品開發各階段即時修改；嚴重度×發生率×偵測度＝RPN（計分依「PFMEA評估準則」）；嚴重度 9/10 直接優先處理；RPN≦100 可暫不處理；特性分類：關鍵特性（嚴重度9-10，PFMEA標註＋製程特別管制）、重要特性（嚴重度5-8且發生率4-10）、一般特性。

**附件**：PFMEA評估準則(3-TD-01-01)、潛在失效模式及效應分析(3-TD-01-02)。

### 3-TD-03 圖面管理辦法

**流程重點**：
1. **繪製**：技術課製作初稿 → 編號（多為治具圖）→ 版次（新圖 A 版起，設變後新舊件不可互換即改版次）→ 繪製 → 主管審查蓋「技術課」章＋日期。
2. **發行**：文管中心確認版次註記 → 蓋「**發行章**」＋日期。
3. **保存**：文管人員上傳上華 ERP 並註記圖面種類；各單位用圖由技術課從 ERP 列印，蓋「各單位印章」＋日期。
4. **設變**：提出「工程變更申請/審查/通知單」會同研討重新繪圖審核。
5. **作廢/收回**：舊圖收回蓋「作廢章」，發行單位保留最近一份備查。

**使用表單**：工程變更申請/審查/通知單(2-TD-01-01)。

## 五、跨課室協作點

- **工程變更**是全廠連動樞紐：任何單位可申請 → 技術課審查 → 總經理核准 → 業務(客戶端)/文管(文件)/生管(圖面簽收單通知廠商)/品保(首件驗收)分頭執行。
- **新品開發**：業務(需求彙整)→技術(C.F.T.評估/出圖)→生管(督導/發包)→生產(試製)→品保(FAI)→業務(送樣接單)。
- **圖面**：技術課繪圖審核 → 文管中心蓋發行章發行 → 上傳 ERP → 設變時舊圖收回作廢。
- **夾治具**：技術(設計出圖)→生管(發包)→生產(驗收/保養/報廢)。
