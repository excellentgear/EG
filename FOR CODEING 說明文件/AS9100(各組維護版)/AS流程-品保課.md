## 一、課室職責（摘自 2-GM-01 管理責任與經營規劃程序）

- 檢驗判定之審核（含外包之檢驗報告）
- 檢測設備校正管理、檢驗員之訓練及認可
- 品質異常、不合格發生及客戶抱怨之原因分析及改善對策之審查追蹤
- 各檢驗文件之制定與修訂；協助審查客戶合約上品質之要求
- 驗證供應商的品質能力
- 公司內部所有矯正及預防措施之監督、管制、追蹤及效果確認
- 產品品質狀況之標示鑑別、隔離不合格之產品
- 檢驗記錄資料保存（含材質證明）

## 三、各程序流程與使用表單

### 2-QA-01 不合格品管理程序

**適用範圍**：進料、製程、委外加工、最終產品、客退品。

**流程重點**：
1. **標示與隔離**：不合格品以「製程管制卡」紅色標示 → 放置不良品區 → 品保開立「品質異常處理單」（必要時附照片）。
2. **特採**：輕微不影響功能且急需 → 需求部門提出 → 相關主管審查 → **總經理核准**；成品特採需**客戶同意**。
3. **選別使用**：權責單位依品質異常處理單勾選處置建議 → 品保安排全檢選別。
4. **重工**：品保會同相關單位 → 結果填「製程管制卡」→ 外包走「重工單」交上一製程；廠內排生產排程 → 重工後依 2-QA-04 再檢。
5. **報廢**：填「製程管制卡」→ 報廢單號登錄「不合格品管制記錄表」；**航太件**貼紅色吊卡、噴紅漆、上鎖鐵櫃管制。
6. **退貨**：進料不合格 → 品保開「品質異常處理單」→ 採購辦退換貨 → 異常登錄「供應商定期評核表」（回饋供應商評核）。
7. **客退**：業務/生管依客戶退貨單點收 → 隔離 → 品保分析責任歸屬 → 按重工/報廢流程 → 責任單位提改善對策並追蹤。
8. **已出貨不合格通報**：發現單位填「品質異常處理單」通知客戶 → 倉管清查庫存下架全篩。

**使用表單**：

|---|---|---|---|
| 2-QA-01-01 | 品質異常處理單 | 品保課 | 發現不合格時開立（核心單據） |

| 2-QA-01-03 | 不合格品管制記錄表 | 品保課 | 登錄報廢單號、航太不良品 |

### 2-QA-02 首件檢驗作業程序（FAI）

**執行時機**：新品首件／停產 2 年再接單／客戶要求／依管制計劃／製程變更（新供應商、新人員、新模治具、換製造地點、變更方法流程參數）。

**流程重點**：
1. **FAI 規劃**：航太件→核對廠內工令單與客戶工作令 → 填「檢驗記錄表」或客戶表格 → 依藍圖規劃量具/量測手法/量測順序 → 資料先送客戶書面確認。非航太件→依「檢驗排程表」核對藍圖版別。
2. **樣品試製**：技術課依 2-TD-02 製程開發執行；需求變更走 2-TD-01 工程變更。
3. **檢驗與驗證**：量測值填「檢驗記錄表」；FORM3 用三次元需附 CMM 數據（含藍圖版別、工單號碼、檢驗人員蓋章）；合格→依 2-PD-01（航太）/2-WH-01（非航太）續流程；不合格→依 2-QA-01。
4. **客戶確認**：客戶檢驗合格由**業務通知品保**；不合格依 2-QA-01。

**使用表單**：檢驗記錄表(2-QA-01-06)、製程單(2-PD-01-01)、FAI表(客戶提供)、工程變更申請/審查/通知單(2-TD-01-01)、品質異常處理單(2-QA-01-01)。

### 2-QA-03 問題分析與解決程序

**流程重點**：品保每月彙總各項檢測記錄（委外加工、成品入庫）→ 統計手法分析（柏拉圖/直方圖/推移圖/管制圖/特性要因圖）→ 管理審查會議提報；發現重大品質問題 → 品保主管決定是否暫停 → 召集跨部門依 2-QA-05 檢討對策。

**使用表單**：無（輸出為統計分析報告，於管審會議提報）。

### 2-QA-04 檢驗與測試管理程序

**流程重點**：
1. **進料檢驗**：進貨單點收 → 移待驗區 → 生管提供藍圖/規範 → 品保隨機抽樣（依 3-QA-03）記錄於「檢驗記錄表」→ 合格依 2-WH-01 入庫；不合格依 2-QA-01。
2. **製程檢驗**：加工首件由現場主管/不同機台操作員/品管確認（末件亦同）→ 生產中至少每小時自主檢查、每日至少一次巡檢，皆記錄於「製程巡查表」。
3. **成品檢驗**：依生管待驗排程表接收核對數量 → 檢驗記錄於「檢驗記錄表」或客戶表單（航太用 FAI 表）→ 合格依 2-WH-01；不合格依 2-QA-01。

**使用表單**：檢驗記錄表(2-QA-01-06)、品質異常處理單(2-QA-01-01)、製程管制卡(2-QA-01-02)、製程巡查表(2-QA-01-09)、出貨檢驗表(2-QA-01-07)、多次加工憑單(2-PH-03-01)、FAI表(客戶提供)。

### 2-QA-05 矯正與預防措施管理程序

**開立時機**：①品質異常處理單判定需檢附時（**航太報廢品一律須檢附**）②客戶端開立矯正預防報告③管理代表針對 KPI 超標時。

**流程重點**：
1. 評估會議判定是否開立「異常矯正處理單」。
2. 品保填寫「品質異常處理單」→ 主管審核 → 登錄「不合格品管制記錄表」→ 分發矯正單位（內部＝責任部門；供應商＝該品項生管人員傳遞）。
3. 回覆期限：主要缺失 7 天、次要缺失 14 天（或依客戶指定）。
4. 矯正單位：臨時對策（清查庫存全篩）→ 原因分析（魚骨圖/5Why）→ 矯正措施 → 預防措施。
5. 追蹤結案：內部由品保/管理代表追蹤 → 品保審核、**總經理核准**結案；供應商由品保視嚴重度安排稽核。

**使用表單**：品質異常處理單(2-QA-01-01)、異常矯正處理單(2-QA-01-04)、不合格品管制記錄表(2-QA-01-03)、會議記錄(2-GM-05-01)。

### 3-QA-01 量規儀器校正管理辦法

**流程重點**：
1. 量具編號規則：`類別-流水號-單位代號`（單位代號：Q品保課/P生產課/T技術課/E其他/H滾齒加工）。
2. 新購儀器驗證合格 → 外箱及機身貼「合格」標籤＋量具雷刻編號。
3. 所有儀器建「檢驗設備履歷表」列帳管理。
4. **每年 12 月底前**品保排定下年度「校驗計畫表」呈總經理簽核 → 內校依 3-QA-02、無法內校者註明外校委外。
5. 合格貼「合格」標籤（註明校驗日期/校驗者/下次校驗日）；不合格貼「禁止使用」標籤送修；免校驗貼「免校正」標籤。
6. 校驗發現不合格 → 使用單位追溯過去量測產品（自主檢驗表/成品檢驗記錄/入庫物料）檢測隔離，已出貨需通知客戶必要時召回。
7. 量測室溫濕度標準：**溫度 20±2℃、濕度 60±10%**，每日登記「量測室溫、濕度記錄表」，異常須立即矯正並同步登錄。
8. 內校人員資格依年度教育訓練表。

**使用表單**：校驗計畫表(3-QA-01-01)、檢驗設備履歷表(3-QA-01-02)、合格標籤(3-QA-01-03)、禁止使用標籤(3-QA-01-04)、免校正標籤(3-QA-01-05)、量測室溫濕度記錄表(3-QA-01-06)。

### 3-QA-02 量規儀器內校作業標準

游標卡尺／分厘卡（塊規為標準件）、三點式缸徑規（環規為標準件）之內校步驟；週期每年一次；校驗範圍涵蓋最大使用範圍之 25/50/75/98%（卡尺）或 25/50/75%（分厘卡）；結果記錄於檢驗設備履歷表並貼標籤。

### 3-QA-03 抽樣檢驗作業說明書

MIL-STD 105E 正常檢驗單次抽樣，一般檢驗水準等級 I；嚴重缺點不允許存在；主要缺點 AQL 2.5（尺寸/硬度/功能）、次要 AQL 4.0（外觀）、輕次要 AQL 6.5（輕微碰傷/細小黑點）；抽樣須分散取樣不可同一容器同一區域。
**使用表單**：檢驗記錄表(2-QA-01-06)、出貨檢驗表(2-QA-01-07)。

## 五、跨課室協作點（品保為關鍵節點的流程）

- **進料**：採購/生管點收（進貨單）→ **品保檢驗** → 倉管入庫（2-WH-01）
- **製程**：生產自主檢查＋**品保巡檢**（2-QA-04）
- **委外**：生管發包（多次加工憑單）→ **品保驗收**（2-PH-03）
- **成品出貨**：**品保最終檢驗** → 倉管包裝出貨（2-WH-01/3-SM-01）
- **客訴**：業務受理 → **品保分析原因** → 責任單位矯正 → 業務回覆客戶（2-SM-02）
- **KPI 異常**：管理代表開異常矯正單 → **品保歸檔保存**（2-GM-04）
- **供應商品質**：進料異常登錄供應商定期評核表 → 影響年度稽核名單（2-PH-01）
