# 量測儀器校驗管理 模組說明（交接文件）

> 用途：本文件供其他 AI／工程師接手修改「量測儀器校驗管理」頁面時閱讀。內含完整檔案、資料表、API、UI、KPI、與**必須遵守的專案慣例**。
> 對應 KPI：2-GM-04-01 第 18 項「量測儀器按時校驗率」。最後更新：2026-07-29（二次：類別旗標＋分頁列；移除本頁重複的新增類別功能）。

---

## 1. 模組概述
- 頁面：`views/QC/tool_calibration.php`（量測儀器校驗管理）。
- 目的：管理量具（量測儀器）的校驗週期與校驗紀錄，作為 KPI #18 的資料來源。
- **核心機制：主檔週期自動推算到期**。每支量具設「校驗週期(月)」與「基準下次應校驗日」；每次登錄校驗完成，系統自動把「下次應校驗日」前滾為 `校驗日 + 週期`。
- 儀器主檔沿用既有 `qc_tool`（量具表），僅**加欄**，未動既有資料。

## 5. KPI 計算（tool_calib_lib.php `tool_calib_kpi_compute`）
月份 M：
- **den（當月應校驗）** = ①已完成紀錄 due_date 落在 M 者 ＋ ②主檔 calibration_due 落在 M 且尚無對應紀錄者（尚待完成）。
- **num（準時完成）** = ① 中 calib_date ≤ due_date(+grace_days 寬限，參數) 者。
- value = den>0 ? num/den*100 : null。
- 僅計 `calib_managed=1` 的量具，且**其類別 `qc_tool_list.calib_required` 須為 1**（欄位存在才加此條件，尚未升級 schema 時行為與加欄前相同）。
- registry key `calibration_ontime`（參數 grace_days，預設 0）；指標 #18 source_mode=auto。

## 6. 權限（RBAC，module='tool_calib'，fail-closed）
- 角色：`tool_calib_view`(校驗唯讀)、`tool_calib_edit`(校驗登錄)、`tool_calib_admin`(校驗管理員)；admin⊃edit⊃view。
- 系統管理者固定全權。判斷在 `tool_calib_lib.php` `tool_calib_perms()`。

## 7. UI 結構（tool_calibration.php）
- **工具列**：統計月份(ymSel, `<input type=month>`)、狀態、搜尋、新增儀器(btnAdd，管理員)、**類別設定(btnCatSet，管理員)**、匯出CSV、列印、角色徽章。（原「類別」下拉已由分頁列取代）
- **統計條**：當月應校驗、準時完成、按時校驗率（目標 ≥95%，<95% 紅字）。
- **類別分頁列**（`#tcTabs`，前端狀態 `curTab`）：`全部` ｜ 各已勾「列入分頁」的類別 ｜ `其他`（需校驗但未設分頁者，有量具才出現）。每個分頁顯示筆數；分頁被取消設定時自動回「全部」。列印時只留目前分頁當標題。
- **分頁列**（tc-pager）：總筆數、每頁 5/10/20/50（預設 10）、上一頁/頁碼/下一頁；篩選搜尋時回第 1 頁。
- **清單表**：量具編號｜類別｜週期(月)｜校驗方式｜下次應校驗日｜狀態｜最近校驗｜納入管理｜操作(登錄/設定/歷史)。
  - 狀態 pill（`tool_calib_status()`）：overdue 逾期 / soon 即將到期(30天內) / ok 正常 / nobaseline 未設基準 / unmanaged 未納管。
- **登錄/編輯校驗 modal**（recMask）：校驗完成日、結果、方式、人員、憑證、備註；編輯既有紀錄由歷史 modal「編輯」進入（`editHis()`，共用 recMask，`editCalibId` 區分）。
- **設定/新增儀器 modal**（setMask）：量具編號、類別（下拉**只列 calib_required=1 且 has_tool_no=1** 的類別；編輯既有量具時若其現行類別不在名單內，會補一個 `option.tmp-cat`「（目前類別）」避免存檔時被誤改）、週期、校驗方式、下次應校驗日(基準)、是否納管。
- **類別設定 modal**（catMask，管理員）：逐類別勾選 需校驗／可設定量具編號／列入分頁（取消「需校驗」會即時鎖住並取消「列入分頁」）；儲存前若有「已納管量具的類別」被取消需校驗會 confirm 警告。類別名稱本身在此頁**不可**新增/更名/刪除，modal 內附連結導到線上檢驗量具設定。
- **校驗歷史 modal**（hisMask）：列出該量具所有紀錄（應校驗到期/校驗日/準時/結果/方式/人員/憑證/下次到期/登錄者），每列可編輯(登錄權)/刪除(管理員)。
- 前端狀態：`ROWS`(全部量具)、`CATS`(類別含旗標)、`curTab`(目前分頁)、`filteredRows()`(篩選)、`tcPage`(分頁)、`HISTORY`/`HIST_TID`(歷史)。
- 清單下方提示會顯示「另有 N 支量具所屬類別未設為需校驗，未列入本頁與 KPI」（`excluded`），避免類別被關掉後資料悄悄消失。

## 8. 上線前置作業（使用者操作）
1. 到「使用者權限設定」指派校驗角色。
2. 進本頁按工具列「類別設定」：把非量具的類別（如「目視」）取消「需校驗」與「可設定量具編號」；把常用類別勾「列入分頁」。
3. 進本頁把要納管的量具設「週期＋下次應校驗日(基準)＋納入管理」。**未設基準到期日者不計入 KPI**（清單標「未設基準」）。

## 10. 已知注意事項/設計要點
- **前滾邏輯**：record_calib 時 due_date = 當下 calibration_due（可能為 null），next_due = calib_date + 週期；並 UPDATE qc_tool.calibration_due = next_due。edit_calib 若編輯的是「最近一次」紀錄才會再前滾主檔。delete_calib 會依剩餘紀錄修復 calibration_due。
- **準時判定**：on-time = calib_date ≤ due_date(+grace_days)。逾期補做（calib_date>due）計 den 不計 num。
- qc_tool 為既有 QC 量具表，其他頁（如檢驗）也用 Tool_No，**勿刪欄或改既有欄語意**，只加欄。
- **類別旗標是跨頁的**：`has_tool_no=0` 的種類，在 `inspection_combined_prototype.php`「量具設定」也會隱藏「新增編號」表單並在 `save_tool_instance` 後端擋下（該頁不含 tool_calib_lib，欄位查詢用 try/catch `PDOException`，欄位不存在時不擋以維持舊行為）。改旗標語意時**兩頁都要看**。
- `calib_required=0` 只是不列入本頁/KPI，**不影響**該類別當作檢驗方式使用（`qc_inspection_item_tool_type` 照舊），所以「目視」仍能在檢驗項目挑選。
- `calibration_due` 是既有欄位，本模組賦予「下次應校驗日」語意並自動維護。
